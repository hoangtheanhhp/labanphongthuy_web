# ☯ Phong Thuỷ PWA (Progressive Web App)

Dự án Webapp Tra cứu Bát Quái Phong Thuỷ Trực Tuyến độc lập, xây dựng bằng **Vite + React 18 + TypeScript + Tailwind CSS + Vite-PWA**.

## 🌟 Tính Năng
1. **Mệnh Quái Bát Trạch**: Tra cứu Cung Phi, Đông/Tây Tứ Mệnh, 4 Hướng Cát & 4 Hướng Hung.
2. **Thước Lỗ Ban 3 Chuẩn**: Thước 52.2cm (Thông Thủy), 42.9cm (Dương Trạch), 38.8cm (Âm Phần) với thanh trượt trực quan.
3. **Dương Trạch Tam Yếu**: Quy tắc Môn - Chủ - Táo và bảng Tọa Hung Hướng Cát cho Bếp.
4. **64 Quẻ Kinh Dịch**: Tra cứu Thoán Từ, Tượng Truyện, ứng dụng phong thủy nhà đất.
5. **Hóa Giải Sát Khí**: Nhận diện và hóa giải các thế sát bằng vật phẩm phong thủy.
6. **Chuẩn PWA Offline-First**: Tự động cài đặt Service Worker, lưu cache offline, có thể cài đặt làm ứng dụng độc lập trên điện thoại/máy tính hoặc nhúng trực tiếp vào WebView APK.

## 🛠️ Lệnh Phát Triển
```bash
# Cài đặt thư viện
npm install

# Khởi chạy môi trường dev
npm run dev

# Biên dịch sản phẩm PWA ra thư mục dist/
npm run build

# Xem thử bản build
npm run preview
```
